STA Utilities Item Image Library

Drop your custom item images into the subfolders in this directory.
The item image picker will include these files automatically.

When the item image picker is enabled, choose Change Image from an editable
item row's context menu on LCARS or mobile sheets, or use the image picker
button on the item sheet. Custom Image opens Foundry's file picker. Choose a
file, then use Apply (or the portrait/token apply buttons for NPCs).

Subfolders:
- log
- milestones
- equipment
- weapons
- starship-weapons
- talents
- focuses
- traits
- injuries
- smallcraft-containers
